# MGScripts
This are a compilation of scripts that are mainly for MG.
This are the results of interest for learning computer programming.
Its not for the mass, for it is unstable and inefficient.


Description 
- Buy.user.js
  This script scans your canvas of all "Buy All" buttons and click them all
When you have an alert for an item(s), this script are for the automatic buy all.

- WPS.user.js
  This Weather Pet Swap are meant to simulate a key press when it detected the weather change.
  Key binds to set up in the mod
  AmberMoon      Ctrl + 1
  Snow           Ctrl + 2
  Thunderstorm   Ctrl + 3
  Clear Skies    Ctrl + 4
  Dawn           Ctrl + 5
  Rain           Ctrl + 6

- AC.user.js
  This script is an simple autoclicker that is meant to fill trough while the the feeding trough is open.



Instructions 
  Both Buy.user.js and WPS.user.js are dependent of either or all this Mods:
    - AriesMod
    - Garden Companion 
    - QPM

  Buy.user.js
    1. go to this link >> https://raw.githubusercontent.com/Ron-Gon/MGScripts/main/Buy.user.js
    2. intall the script
    3. restart the game 
  auto starts after enabling and restarting the webpage

  AC.user.js
    1. go to this link >> https://raw.githubusercontent.com/Ron-Gon/MGScripts/main/AC.user.js
    2. install the script
    3. restart the game
    4. open your feeding trough
    5. put the red pointer in the fill trough
    6. click the Clicker: on/off at the top right
    the interval is default set 10 minutes

  WPS.user.js
    1. go to this link >> https://raw.githubusercontent.com/Ron-Gon/MGScripts/main/WPS.user.js
    2. install the script
    3. restart the game
    4. set your key binds in your preferred mod
  script default Key binds
  AmberMoon      Ctrl + 1
  Snow           Ctrl + 2
  Thunderstorm   Ctrl + 3
  Clear Skies    Ctrl + 4
  Dawn           Ctrl + 5
  Rain           Ctrl + 6
